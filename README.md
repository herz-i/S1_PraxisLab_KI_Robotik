# PraxisLab KI & Robotik

## Set-Up

1. Clone the repo
2. Create venv & activate
```
python3 -m venv venv
source venv/bin/activate
```

3. Install deps
```
pip install -r requirements.txt
```

4. Update coordinate transform in **line 46-48** in **src/coord_transform.py** according to robot number.

5. Follow instructions to use prepared scripts according to **Anleitung_myCobot.pdf**
